Blastradius

An AI tool gets a job and some access. You decide how much. Then a bad day tests your choice.

OffThe tool can’t see that system at all.
ReadThe tool can look, but it can’t change anything.
Read and writeThe tool can change things, and nobody checks first.
Job 1 of 3

    What to remember

    Name the one system the job needs. Everything else stays off.
    Start read-only. Add write only when the job truly changes something, and limit it to one place.
    Use a lock, not a note. A limit the system enforces holds. An instruction in the prompt can be talked out of it.
